# 01: Tracer bullet: `get` end to end, `version` and CI

**What to build:** The user sets `database` in the `config`, runs `kdbx-secrets get AWS/paper-freeze`, types the password and receives the Password on stdout. It is the narrowest path that goes through every layer: the CLI entry point with the injected environment (args, env, terminal, stdin/stdout/stderr, whether stdout is a tty, clock), the minimal reading of the `config`, the check of the KDBX signature and of the KDF parameters in the header before the prompt, a simple prompt (one attempt) through the injected terminal, the opening with `gokeepasslib` and the resolution of a path Reference without `#` (Password). It includes `version`, with the version injected at build time (falling back to `dev`), the exit codes 0/1/2 and the CI workflow.

It also creates the versioned script that generates the `.kdbx` fixtures with `keepassxc-cli` (the fixtures are committed and CI does not run the script). This closes pending item 1: opening with `gokeepasslib` the Argon2d, Argon2id and AES-KDF Databases generated by KeePassXC. The special-case fixtures (Attachment, TOTP, duplicate, Recycle bin, expired, `{REF:}`, title with control characters, `TOTP` attribute, one with a realistic KDF) can be generated right here or added by the tickets that use them.
