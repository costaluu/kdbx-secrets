# 14: `encrypt -r` (no prompt)

**What to build:** `encrypt -r <public-key-file> [-r ...]` encrypts stdin to stdout in armored OpenPGP with `ProtonMail/go-crypto` (ADR 0002), without opening the Database and without a prompt. It requires at least one recipient. Clear errors for a post-quantum key and for a public key without an encryption subkey. Compatibility is proven with keys generated by `gpg` and committed in `testdata/`: `gpg` decrypts what the binary encrypted. A script regenerates this test data, but CI does not run it.
